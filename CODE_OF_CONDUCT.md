# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind, and
keep discussions about the work. Financial situations are personal — never
pressure anyone to share real financial data, and never mock anyone's
finances in issues or discussions.

Report unacceptable behavior privately to the maintainer via the contact
listed on the repository profile. Reports are handled confidentially.
